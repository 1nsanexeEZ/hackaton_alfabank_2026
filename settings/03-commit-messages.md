# 03. Сообщения коммитов

## Правило

Каждый коммит начинается с префикса типа изменения:

```
<тип>: <что сделано>
```

| Префикс | Когда |
|---|---|
| `feat:` | Новая функциональность |
| `fix:` | Исправление бага или конфигурации |
| `hotfix:` | Срочный фикс того, что уже сломалось на стенде или в `main` |
| `refactor:` | Переделка без изменения поведения |
| `docs:` | Только документация |
| `test:` | Только тесты |
| `ci:` | GitHub Actions, деплой |
| `chore:` | Зависимости, конфиги, прочая рутина |

- После префикса — коротко, что сделано, со строчной буквы, без точки в конце.
- Один коммит — одно изменение. Если просится два префикса, это два коммита.

Примеры:

```
feat: scoring rules for working capital loans
fix: login by phone with leading 8
docs: describe identity module
ci: run tests before deploy
```
