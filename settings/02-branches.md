# 02. Ветки

## Правило

- **`main` и `develop` не трогаем.** Никаких прямых коммитов и пушей в них, никаких force-push.
- Работаем так: подтянули свежий `develop` → от него сделали свою ветку → в ней работаем.
- Ветка = одна задача (ишью). Название по шаблону:

  ```
  <тип ишью>/<номер ишью>-<название>
  ```

  Тип берём из ишью: `feature` или `bug`. Название — коротко, латиницей, через дефис.

  Примеры:
  ```
  feature/12-scoring-model
  bug/27-deploy-env-vars
  ```

## Как начать задачу

```bash
git checkout develop
git pull
git checkout -b feature/12-scoring-model
```

Нет ишью — сначала заводим ишью, потом ветку.

## После вливания — удаляем ветку

- Ветку влили в `develop` — удаляем её сразу и везде: на GitHub (кнопка «Delete branch» в PR), локально и worktree, если он был.
- Хвосты тоже чистим: влитые, но не удалённые ветки и брошенные (задача закрыта или отменена). Перед началом новой задачи — быстрый просмотр.
- `main` и `develop` не удаляем никогда.
- Чужую ветку удаляем, только если она влита в `develop` или автор подтвердил, что она не нужна.

```bash
git fetch --prune                        # забыть ветки, уже удалённые на GitHub
git branch --merged origin/develop       # локальные ветки, влитые в develop
git branch -r --merged origin/develop    # то же на GitHub
git branch -d feature/12-scoring-model   # удалить локальную (-d не даст удалить невлитую)
git push origin --delete feature/12-scoring-model
git worktree remove <путь>               # если работали в worktree
```

## Для агентов

- Агент никогда не коммитит и не пушит в `main` / `develop`, даже если его об этом попросили в процессе работы — сначала создаёт ветку по шаблону.
- Номер и тип ишью агент берёт из задачи. Если их нет — спрашивает, а не придумывает.
- Префиксы агентов в названии ветки (`claude/...`, `copilot/...`) запрещены — см. [01-commits.md](01-commits.md).
- Ветку, которую агент влил (или которую влили по его PR), он удаляет: на GitHub, локально и свой worktree.
- Найденные хвосты агент сначала показывает пользователю списком; чужие ветки на GitHub удаляет только после подтверждения.
