# external-mocks

Отдельный HTTP-сервис, который **имитирует внешние системы** кредитного конвейера:
ЕГРЮЛ/ЕГРИП, ФНС «Прозрачный бизнес», ГИР БО, Контур.Фокус, БКИ компаний и физлиц, перечни
Росфинмониторинга, база публичных должностных лиц (ПДЛ), платформа «Знай своего клиента» (ЗСК)
Банка России, АБС (выдача) и ЭДО (подписание).

Реальных интеграций в решении нет (автономность). Но, по требованию экспертов, тестовые
данные проходят через **настоящую интеграцию**: это полноценный сервис с «чужим» форматом,
а бэкенд ходит в него через адаптеры. Заменить мок на реальный API = поменять адаптер,
домен не трогаем.

> **Всё смоделировано.** Данные синтетические, операции АБС/ЭДО помечены `simulated: true`,
> никаких реальных реестров и денежных операций. См. `THIRD_PARTY_NOTICES` в корне репозитория.

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/egrul/{inn}` | ЕГРЮЛ/ЕГРИП: статус (`ACTIVE`, `LIQUIDATING`, `LIQUIDATED`, `BANKRUPT`, `REORGANIZING`, `EXCLUDED`), дата регистрации, ОКВЭД, руководитель, учредители (физлица — `ФИО`, юрлица — `Наим` и `ИНН`), адрес, записи о недостоверности сведений (`СведНедостоверн`) (ключи кириллицей) |
| `GET` | `/fns/{inn}` | «Прозрачный бизнес»: недоимка, численность, выручка/расходы, режим, дисквалификация, массовый руководитель (`mass_head`), реестр МСП, блокировки счетов (`account_blocks`) |
| `GET` | `/gir-bo/{inn}` | ГИР БО: бухотчётность за два последних года, коды строк форм 0710001/0710002 в тыс. руб. У ИП и компаний младше года — `available: false` и `reason` |
| `GET` | `/kontur/{inn}` | Контур.Фокус: надёжность, арбитраж, исполнительные производства, сообщения о банкротстве, госконтракты, залоги; суммы в рублях |
| `POST` | `/bki/report` | Кредитный отчёт компании по `{inn, consent_at, request_id}` |
| `POST` | `/bki/person-report` | Кредитный отчёт физлица по `{last_name, first_name, middle_name, company_inn, consent_at, request_id}`; формат — как у отчёта компании плюс `subject` |
| `POST` | `/rfm/screen` | Перечни Росфинмониторинга по `{subjects: [{id, type: UL\|FL, name, inn}]}`: экстремизм и терроризм (`ЭКСТРЕМИЗМ_ТЕРРОРИЗМ`), решения МВК о замораживании (`МВК`), распространение ОМУ (`ФРОМУ`); организация сверяется по ИНН, физлицо — по ФИО |
| `POST` | `/pep/screen` | База ПДЛ по `{persons: [{id, fio}]}`: категория (`ИПДЛ`, `РПДЛ`, `МПДЛ`) и должность или `null` |
| `GET` | `/zsk/{inn}` | Платформа ЗСК: уровень риска `НИЗКИЙ` / `СРЕДНИЙ` / `ВЫСОКИЙ` |
| `GET` | `/abs/stop-list/{inn}` | Внутренний стоп-лист банка: `listed`, `reason`, `listed_at` |
| `POST` | `/abs/disbursements` | Выдача (смоделирована) |
| `POST` | `/edo/sign` | Подписание (смоделировано) |
| `GET` | `/health` | Проверка живости (chaos не затрагивает) |

Форматы намеренно «не наши»: суммы — в копейках целым числом, даты — строками, ключи ЕГРЮЛ —
кириллицей. ACL-адаптеры в `backend/src/modules/enrichment/infrastructure/adapters/` переводят это
в наши DTO.

## Данные

- 7 демо-компаний — строго как в сидах бэкенда (`backend/seed/demo_data.py`; даты регистрации
  считаются относительно текущего дня). ИНН/ОГРН с верными контрольными цифрами, менять нельзя.
- Любой другой **валидный** ИНН → детерминированная генерация по хешу (тот же ИНН → тот же ответ),
  чтобы жюри могло пройти сценарий со своей компанией.
- Невалидный ИНН → `404`. БКИ без `consent_at` → `400` (218-ФЗ). ИНН из `MOCK_BKI_ALWAYS_FAIL_INNS` → `503`
  (у отчёта физлица — по `company_inn`).
- ГИР БО, Контур и БКИ физлица (`app/dossier.py`): для демо-компаний — сценарии под сиды бэкенда
  (Закат — блокировка счёта, отрицательный капитал, исполнительные производства и иски; его руководитель —
  с текущей просрочкой 45 дней), для остальных ИНН — генерация по хешу. Отчёт физлица по демо-сценарию
  отдаётся, только если ФИО совпало с руководителем компании в реестре; иначе — генерация по ФИО и ИНН.

- Проверки по 115-ФЗ (`app/compliance.py`): демо-компании бэкенда и их люди чистые, уровень ЗСК
  низкий — сценарии S-1…S-9 от проверок не меняются. Для показа проверок — компании, которых нет
  в сидах (завести в кабинете по ИНН):

  | 7707115023 | Ледник | руководитель — в решении МВК о замораживании |
  | 7707115030 | Посольский двор | бенефициар (75%) — иностранное ПДЛ |

## Поведение (chaos)

Для всех путей, кроме `/health`: случайная задержка `MOCK_LATENCY_MS_MIN..MAX` и доля ответов `503`
= `MOCK_FAILURE_RATE` (по умолчанию в `Dockerfile` — 200–1500 мс и 0.1) — чтобы в бэкенде были видны
таймауты и ретраи. В `docker-compose.yml` для демо «хаос» выключен: 100–400 мс и 0. В тестах — 0.

