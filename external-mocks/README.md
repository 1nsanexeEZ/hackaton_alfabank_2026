# external-mocks

Отдельный HTTP-сервис, который **имитирует внешние системы** кредитного конвейера:
ЕГРЮЛ/ЕГРИП, ФНС «Прозрачный бизнес», БКИ, АБС (выдача) и ЭДО (подписание).

Реальных интеграций в решении нет (автономность). Но, по требованию экспертов, тестовые
данные проходят через **настоящую интеграцию**: это полноценный сервис с «чужим» форматом,
а бэкенд ходит в него через адаптеры. Заменить мок на реальный API = поменять адаптер,
домен не трогаем.

> **Всё смоделировано.** Данные синтетические, операции АБС/ЭДО помечены `simulated: true`,
> никаких реальных реестров и денежных операций. См. `THIRD_PARTY_NOTICES` в корне репозитория.

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/egrul/{inn}` | ЕГРЮЛ/ЕГРИП: статус, дата регистрации, ОКВЭД, руководитель, учредители, адрес (ключи кириллицей) |
| `GET` | `/fns/{inn}` | «Прозрачный бизнес»: недоимка, численность, выручка/расходы, режим, дисквалификация, реестр МСП |
| `POST` | `/bki/report` | Кредитный отчёт по `{inn, consent_at, request_id}` |
| `POST` | `/abs/disbursements` | Выдача (смоделирована) |
| `POST` | `/edo/sign` | Подписание (смоделировано) |
| `GET` | `/health` | Проверка живости (chaos не затрагивает) |

Форматы намеренно «не наши»: суммы — в копейках целым числом, даты — строками, ключи ЕГРЮЛ —
кириллицей. ACL-адаптер в `backend/src/enrichment` переводит это в наши VO.

## Данные

- 6 демо-компаний — строго по `00-common.md` §9.1–§9.2 (даты регистрации считаются относительно
  текущего дня). ИНН/ОГРН с верными контрольными цифрами, менять нельзя.
- Любой другой **валидный** ИНН → детерминированная генерация по хешу (тот же ИНН → тот же ответ),
  чтобы жюри могло пройти сценарий со своей компанией.
- Невалидный ИНН → `404`. БКИ без `consent_at` → `400` (218-ФЗ). ИНН из `MOCK_BKI_ALWAYS_FAIL_INNS` → `503`.

## Поведение (chaos)

Для всех путей, кроме `/health`: случайная задержка `MOCK_LATENCY_MS_MIN..MAX` и доля ответов `503`
= `MOCK_FAILURE_RATE` (по умолчанию 0.1) — чтобы в бэкенде были видны таймауты и ретраи. В тестах — 0.

## Запуск

```bash
uv sync
uv run uvicorn app.main:app --host 0.0.0.0 --port 8100
# проверки
uv run ruff check . && uv run ruff format --check . && uv run pytest
```

Переменные окружения — см. `.env.example`.
